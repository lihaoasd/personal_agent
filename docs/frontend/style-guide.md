# 个人成长管理助手 Agent — 前端风格文档

- 版本：v0.1
- 日期：2026-09-12
- 技术栈：Vue3 + Vite + TypeScript + Element Plus + Vue Router + axios

## 1. 视觉风格（v0.6 萌系重设计）

- 主题：奶油色系 + 大圆角 + emoji 图标，柔和可爱风（非后台管理风）
- 主色：柔和薄荷绿 `#7BC8A4`（渐变 `#7BC8A4 → #9DD8BA`），辅助粉 `#FFB5C5`、橙 `#FFD4A3`、紫 `#D4C5F0`
- 背景：奶油米白 `#FFF9F2`；侧边栏 `#FFFCF7`
- 卡片：白底 + 20px 大圆角 + 1px 柔和边框 `#F0EBE3`，几乎无硬阴影
- 文字：柔和深灰 `#4A4A4A`，次要 `#9A9A9A`（不用纯黑）
- 按钮：渐变圆角 16px，hover 上浮 + 柔和阴影
- 图标：全部用 emoji（💬🎯📅📝📊⚙️🌱），不用线性图标库
- 聊天气泡：用户侧薄荷绿渐变，助手侧白色柔和边框
- 统计卡片：4 色渐变背景（薄荷/桃/粉/紫）+ emoji
- 交互细节：hover 微上浮、齿轮按钮 hover 旋转 30°

## 2. 布局

- 整体：左侧 200px 奶油色导航（emoji logo + emoji 菜单 + 底部状态）+ 右侧 64px 顶部栏（标题 + 鼓励语日期）+ 主内容区
- 配置入口：右下角固定圆形按钮（52×52，粉橙渐变，emoji ⚙️，hover 旋转），点击弹出「设置」抽屉（rtl，500px）
- 页面统一 `max-width: 1080px` 居中，内容区上下留白 24px

## 3. 页面与组件约定

| 页面 | 核心组件 | 要点 |
|---|---|---|
| ChatView（对话打卡） | 消息列表、输入框、气泡、快捷模板栏 | 用户右对齐、助手左对齐；助手气泡支持 Markdown 渲染；模板一键打卡 |
| GoalsView（目标/学习计划） | 目标卡片、进度条、任务列表 | 进度 = done/total；按 category 分组（学习/健康/习惯）；状态标签 |
| SchedulesView（日程管理） | 日历视图、日程列表 | 按周/月切换；日程支持标记完成 |
| ReviewsView（复盘） | 复盘卡片、Markdown 展示 | 按周期倒序，展示区间与生成时间 |
| DashboardView（看板） | 统计卡片、周打卡天数、类型分布、目标进度条 | 数字来自 `/api/stats/dashboard`；不展示连续天数（宽容口径） |
| SettingsDrawer（设置抽屉） | 配置项列表 + 表单区 | 右下角齿轮按钮打开；配置项左列（模型配置），内容右区；新增配置在 `sections` 列表追加 |

## 4. 交互与响应式

- 聊天发送：Enter 发送、Shift+Enter 换行；发送后清空输入框并滚动到底部
- 加载态：LLM 回复期间输入框禁用并显示「思考中…」
- 所有列表支持空态提示，不显示空白页
- 移动端：聊天输入框固定底部，页面单列，字号 ≥14px

## 5. 工程约定

- axios 统一实例：`src/api/client.ts`，baseURL `/api`，统一错误提示（ElMessage）
- 时间展示：后端 ISO 字符串 → `dayjs` 本地格式化
- 组件命名：PascalCase；视图文件后缀 `View`
- 不引入额外 UI 库之外的样式框架；全局样式仅定义主题变量与通用类
