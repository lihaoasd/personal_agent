# 个人成长管理助手 Agent — 需求文档

- 版本：v0.3
- 日期：2026-09-12
- 状态：待确认（范围已收敛；剩余待定项见 §10）

## 1. 背景与目标

打造一个以「长期记忆 + 心理学方法」为核心的桌面端个人成长管理 Agent，把「设定目标 → 执行记录 → 周期复盘」闭环自动化，并在每个环节嵌入基于实证心理学的行为干预。

与打卡 App、笔记工具的差异：AI 记住用户目标与历史，**用心理学方法帮用户持续行动**，而非只提供表单和存储。

## 2. 产品定位

- 形态：桌面端应用（本地优先，数据留在本机）
- 角色：成长教练（记录 + 计划 + 心理干预 + 洞察），而非单纯工具
- 核心循环：计划 → 记录 → 复盘 → 调整，心理学贯穿全程
- 头号设计目标：**对抗「记录疲劳」**——让记录几乎不费力、每次都有回报

## 3. 目标用户与核心场景

目标用户：有成长诉求但缺乏持续性的个人用户（自用起步）。

| 场景 | 描述 | 频率 |
|---|---|---|
| 目标与学习计划 | 用自然语言定目标/学习计划，AI 按心理学原则拆解 | 低频 |
| 日程管理 | 日程与任务排期，桌面日历视图 | 每日 |
| 对话记录 | 阅读笔记 / 健康记录 / 习惯打卡，统一对话式记录 | 每日 |
| 心理干预 | 中断关怀、习惯引擎、执行意图提醒 | 每日/按需 |
| 周复盘 | 自动生成含心理维度的复盘报告 | 每周 |
| 成长看板 | 打卡率、目标进度、周内天数 | 随时 |

## 4. 功能范围

### MVP（P0）

1. **目标管理**：目标设置向导（SMART + 执行意图 If-Then 计划）、子任务、进度跟踪
2. **学习计划**：学习目标 → 计划拆解（课程/书籍/实践）→ 进度追踪 → 复习提醒（间隔重复基础版）
3. **日程管理**：日程 / 任务排期、桌面日历视图
4. **统一记录层**：对话打卡，一条链路覆盖 阅读笔记 / 健康记录 / 习惯打卡（事件类型区分）
5. **心理学管理（横切层）**：习惯引擎（2 分钟法则 / 习惯叠加）、即时正反馈、中断干预（自我慈悲话术）、动机设计（难度自适应）
6. **周复盘**：含心理维度（过程归因 / 下周可行动建议）
7. **成长看板**：打卡率、目标进度、周内天数、近期明细
8. **记录防疲劳机制（横切层）**：主动问询、快捷模板、允许补记、宽容统计、低密度模式（细则见 §6）

### 后置（P1）

- 智能提醒（桌面系统通知）
- 每日一句话 + 情绪记录
- AI 模式洞察（行为规律挖掘）
- 自然语言查询（对话式问数）
- 专注计时（番茄钟）
- 自动采集（日历/计时自动生成记录草稿）
- 数据导入导出（Markdown / JSON 备份）

### 暂不做

- 多端同步 / 移动端
- 财务健康
- 社交分享
- 知识图谱

## 5. 心理学管理细则

| 心理学原则（来源） | 落地功能 | 用户价值 |
|---|---|---|
| 执行意图 If-Then（Gollwitzer） | 目标设置向导生成「如果…就…」计划 | 执行率提升，减少"想不起来做" |
| 微小习惯 / 2 分钟法则（Fogg） | 习惯引擎拆出 2 分钟起步动作、习惯叠加 | 降低启动阻力，缓解拖延 |
| 习惯回路 提示-行为-奖励 | 打卡后即时正反馈 | 行为固化，不等周复盘才有反馈 |
| 自我慈悲（Neff） | 连续中断时温和重启话术 | 防止「破罐破摔」，降低放弃率 |
| 成长型思维（Dweck） | 复盘聚焦过程与可控归因 | 避免自我标签化，形成学习型归因 |
| 自我决定理论（Deci & Ryan） | 目标关联个人价值、难度自适应 | 保护内在动机，避免过载挫败 |

**合规边界（强制）**：心理学管理仅提供自我管理辅助（话术、框架、提醒），不提供心理测评诊断、不声称治疗效果、不替代专业心理咨询或医疗服务；涉及情绪健康异常信号时提示寻求专业帮助。

## 6. 记录防疲劳机制（横切设计）

**核心公式：记录意愿 = 记录收益 − 记录成本**

### 降成本

| 机制 | 说明 | 优先级 |
|---|---|---|
| 主动问询 | 每晚固定时间 Agent 主动问「今天怎么样？」，用户回一句即完成记录 | P0 |
| 一句话完成 | 自然语言即记录，无表单；桌面端支持语音输入 | P0 |
| 快捷模板 | 高频习惯一键打卡，零输入 | P0 |
| 允许补记 | 不强制当天，忙时少记、周末可补 | P0 |
| 自动采集 | 日历/番茄钟自动生成记录草稿，用户一键确认 | P1 |

### 提收益

| 机制 | 说明 | 优先级 |
|---|---|---|
| 即时反馈 | 打卡后立刻回进度与鼓励 | P0 |
| 周复盘回报 | 记录越全、复盘越值，把记录变成「下周更聪明」的投资 | P0 |
| 成长可视化 | 贡献图式积累可见 | P0 |
| 意义回顾 | 定期回看「这一周积累了什么」 | P1 |

### 贯穿性心理机制

| 机制 | 说明 |
|---|---|
| 宽容机制 | 中断不惩罚、不显示红色断点；统计口径用「本周 X/7 天」而非「连续 N 天」，防破罐破摔 |
| 可变奖励 | 偶尔的洞察与回顾惊喜，保持新鲜感 |
| 内化连接 | 帮助用户看见记录与个人价值的关联，保护内在动机 |
| 低密度模式 | 允许少量记录，周复盘照常生成并说明「本周记录较少」 |

## 7. 用户故事

- 作为用户，我用一句话设定目标，AI 帮我按心理学原则拆成可执行、可坚持的计划。
- 作为用户，我每天用自然语言打卡阅读/健康/习惯，AI 记录并即时反馈。
- 作为用户，我中断几天时，AI 不指责，而是帮我想怎么重启。
- 作为用户，我每周收到含心理维度的复盘，知道卡在哪、下周怎么调整。
- 作为用户，我可以在桌面日历上看到日程、学习计划与任务排期。
- 作为用户，我忙的时候只记一两句也没关系，复盘照常生成。

## 8. 成功标准与验收

| 标准 | 验收方式 |
|---|---|
| 一次打卡 ≤ 1 分钟 | 端到端走查：打卡 → 记录 → 即时反馈 |
| 主动问询可用 | 定时触发的问询对话可完成一次记录 |
| 中断干预温和有效 | 连续 3 天未打卡后，回复话术无指责、含重启建议 |
| 宽容统计生效 | 中断后看板显示「本周 X/7」而非红色断点 |
| 周复盘含心理维度 | 复盘包含过程归因与下周可行动建议 |
| 看板与记录一致 | 看板数字可由 events/goals 表重算验证 |
| 数据本地存储 | 无网络依赖下功能可用（LLM 调用除外） |

## 9. 边界与约束

- 桌面端本地运行，数据存本地数据库；无账号体系（单用户）
- LLM 走 OpenAI 兼容接口，端点 / 密钥 / 模型可配置
- 时区固定 Asia/Shanghai
- 心理学内容限自我管理辅助，见 §5 合规边界
- 不采集第三方数据；用户数据除 LLM API 调用外不外发
